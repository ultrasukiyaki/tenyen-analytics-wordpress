# Security Policy

## Supported versions

Security fixes are provided for the current release line. Version 0.5.6 is currently supported; administrators should update from older versions.

## Reporting a vulnerability

Report suspected vulnerabilities privately to the maintainer through the contact channel at [10yendama.com](https://www.10yendama.com/). Include the affected version, reproduction steps, impact, and any suggested mitigation. Do not open a public issue or disclose details before a fix is available. We will acknowledge the report, investigate it, coordinate remediation, and credit reporters when requested.

Never include real visitor data, decrypted IP addresses, WordPress salts, nonces, passwords, or production database exports in a report.
